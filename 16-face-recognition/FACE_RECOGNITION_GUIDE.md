# 企业级人脸识别落地架构与准确率达标指南

## 1. 概念纠偏：YOLO 真的能做“人脸识别”吗？

很多初学者甚至部分企业技术人员会混淆两个极其核心的 AI 概念：
1. **人脸检测 (Face Detection)**：告诉你图片中**哪里有人脸**，画一个框框出来。
2. **人脸识别 (Face Recognition)**：告诉你框里的这张脸**到底是谁**（张三还是李四）。

**YOLO (You Only Look Once)** 是当今世界上最顶尖的 **检测模型**，但它并不能用来直接做**识别**。如果强行用 YOLO 做识别（比如把张三作为 YOLO 的一个分类），只要公司新入职一个员工，YOLO 就要重新训练一次，这在工程上是绝对反人类的。

### 工业界黄金架构 (Pipeline)
真正的企业级落地，必须是 **“YOLO 定位 + ArcFace 识别”** 的两级架构：
1. 先用 **YOLOv8** 模型进行极速扫描，在复杂的背景人群中把人脸精准裁剪下来。
2. 将裁下的人脸喂给 **ArcFace**（或 Facenet 等模型），提取出具有极高区分度的 `512维` 数学向量。
3. 把这个向量去和数据库（FAISS / Milvus）中的底片向量计算余弦相似度。只要距离够近，就是同一个人！由于提取特征的模型不需要随着员工增加而重新训练，这种架构极其强壮。

---

## 2. 代码实现方案：DeepFace + FastAPI
我们在代码中采用了基于 Python 的 `DeepFace` 库。这是目前最优雅的工业级人脸处理框架。
* 它内置了 `detector_backend='yolov8'`，完美满足了你要求使用 YOLO 的检测需求。
* 它内置了 `model_name='ArcFace'`，在 LFW 数据集上的识别准确率高达 **99.8%**，远超 90% 的硬性指标。
* 我们使用 **FastAPI** 将其包裹为了一个极速异步的 HTTP 接口，可以直接供前端或硬件（如门禁系统）调用。

## 3. 如何进行 90% 的达标验收测试？

要证明我们的模型准确率达到了 90% 以上，你需要建立一个真实的测试集并运行自动化测试脚本。

### 3.1 准备数据结构
在项目目录下创建底库和测试集：
```text
├── local_face_db/         <-- (这是底库，每人放 1-2 张极其清晰的正脸证件照)
│   ├── zhangsan.jpg
│   └── lisi.png
├── test_dataset/          <-- (这是测试集，放真实的复杂抓拍照片)
│   ├── zhangsan/
│   │   ├── 打卡抓拍1.jpg
│   │   └── 戴口罩照片2.jpg
│   └── lisi/
│       └── 侧脸抓拍1.jpg
```

### 3.2 运行步骤
1. 启动 HTTP 后端服务：
   ```bash
   python face_api.py
   ```
2. 新开一个终端，执行自动化压测脚本：
   ```bash
   python test_accuracy.py
   ```

### 3.3 遇到准确率不达标怎么办？
虽然 ArcFace 理论准确率 99.8%，但在真实环境由于光线、摄像头老化，依然可能掉到 90% 以下。**AI 工程师的常用调优手段：**
1. **换检测器**：如果被测试人脸太小，把 `yolov8` 替换为 `retinaface`（对极小人脸检测极度敏感）。
2. **调参阈值**：在 `face_api.py` 中，ArcFace 的默认距离判定阈值是 `0.68`。
   * 如果总是**认错人 (误识)**：把阈值调严，比如改到 `0.60`。
   * 如果总是**认不出来 (拒识)**：把阈值放宽，比如改到 `0.75`。
3. **清洗底库**：保证 `local_face_db` 里面的照片必须是绝对纯净的单人、无遮挡正脸！底库拉胯，神仙难救。
